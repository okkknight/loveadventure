# 恋爱求生宝典

一个手机端优先的网页小游戏。  
你不是来学标准答案的，你是来看看自己在恋爱高危场景里靠什么活下来。

## 这是个什么

- 恋爱选择题小游戏
- 每局随机 10 题
- 每题 3 个回答风格：稳住型、拆题型、整活型
- 答完后生成一份有梗的恋爱求生报告

## 技术栈

- React
- Vite
- Tailwind CSS
- Framer Motion
- Zustand

## 本地运行

```bash
npm install
npm run dev
```

## 功能范围

- 首页
- 规则弹层
- 随机 10 题
- 选择后系统反馈
- 结果页
- 再玩一次
- 分享结果

## 说明

- 不需要后端
- 不需要登录
- 不需要数据库
- 刷新页面后直接重新开始
- 目标是轻松好笑，不做严肃测评
