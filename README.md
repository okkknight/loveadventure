# 恋爱求生宝典

你以为自己很会说话，直到恋爱高危场景真的出现。

恋爱求生宝典是一局两三分钟的手机网页选择题游戏。聊天回复、情绪安慰、送命题、纪念日、吵架修复……每题只有一次选择机会。你选的不是标准答案，而是自己的求生姿势：先稳住、认真拆题，还是直接整活。

![恋爱求生宝典主视觉：笔记本、纸飞机与救生圈](public/assets/love-home-hero.png)

十题结束后，它会给出一份有梗、带一点调侃的恋爱求生报告。它不做严肃测评，只想让人玩完笑一下。

## 一局怎么玩

1. 每一局随机抽 10 道题，题目和选项顺序都会变。
2. 选一个你真会说出口的回应，立刻看游戏怎么吐槽。
3. 答完收下报告：三种风格的比例、一句总结，还有可以转发给朋友的战报。
4. 点“再玩一次”，再开一局。

手机端优先设计，也可以在桌面浏览器里玩。无需账号；游戏状态只在当前页面中，刷新后会重新开始。

## 本地运行

需要 Node.js 和 npm：

```bash
npm install
npm run dev
```

Vite 会在终端显示本地地址。构建静态站点使用 `npm run build`，产物在 `dist/`。目前没有经过确认的公开在线游戏地址。

## 源码与许可

题目和回应写在 [`src/data/questions.js`](src/data/questions.js)，抽题、计分和报告逻辑在 [`src/store/gameStore.js`](src/store/gameStore.js)。前端使用 React、Vite、Tailwind CSS、Framer Motion 和 Zustand，不需要后端或数据库。
